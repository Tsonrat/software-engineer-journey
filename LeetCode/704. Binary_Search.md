# 0704. Binary Search

## Description

Given an array of integers `nums` which is sorted in ascending order,
and an integer `target`, return the index of `target` if it exists.

If `target` does not exist, return `-1`.

You may assume that all elements in `nums` are unique.

---

## Example

### Example 1

**Input**

```text
nums = [-1,0,3,5,9,12]
target = 9
```

**Output**

```text
4
```

---

### Example 2

**Input**

```text
nums = [-1,0,3,5,9,12]
target = 2
```

**Output**

```text
-1
```

---

# My Solution

## Solution 1 - Binary Search

```java
class Solution {
    public int search(int[] nums, int target) {

        int left = 0;
        int right = nums.length - 1;

        while (left <= right) {

            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                return mid;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        return -1;
    }
}
```

Binary Search 利用陣列已排序的特性，每次比較中間元素後即可排除一半的搜尋範圍。

- 若 `nums[mid] == target`，直接回傳 `mid`
- 若 `nums[mid] < target`，代表答案只可能在右半邊
- 若 `nums[mid] > target`，代表答案只可能在左半邊

因此每次搜尋都會將搜尋範圍縮小一半。

---

# Note

## Binary Search

Binary Search 必須建立在 **已排序陣列** 上。

利用中間值 (`mid`) 與 `target` 比較，不斷縮小搜尋範圍。

---

## Search Range

搜尋範圍利用兩個指標表示：

```java
int left = 0;
int right = nums.length - 1;
```

每次重新計算：

```java
int mid = left + (right - left) / 2;
```

此寫法可以避免 `(left + right)` 發生 Integer Overflow。

---

## Why `left <= right` ?

當

```text
left == right
```

時，仍然還有最後一個元素需要檢查。

只有當

```text
left > right
```

代表搜尋範圍完全不存在，才結束搜尋。

因此：

```java
while (left <= right)
```

而不是

```java
while (left < right)
```

---

## Why `mid + 1` / `mid - 1` ?

當 `nums[mid]` 已經比較過後，就知道它不是答案（除非已經 return）。

因此下一次搜尋必須排除 `mid`。

```java
left = mid + 1;
right = mid - 1;
```

如果寫成：

```java
left = mid;
```

或

```java
right = mid;
```

有可能造成搜尋範圍無法縮小，形成無限迴圈。
